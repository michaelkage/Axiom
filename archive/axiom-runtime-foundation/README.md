# Archived Axiom runtime foundation

This is the earlier VS Code extension-oriented runtime foundation from `feat/axiom-runtime-foundation`.

It is retained for reference, not included in the active desktop or mobile PWA builds. Its source depends on the VS Code extension host and the legacy extension shell; the active product now builds as a standalone desktop app plus the independent React PWA in `pwa/`.

The original branch and all its commits are also retained in the integration commit's ancestry.
