Not just code generation.

Axiom is built around the work surrounding a change: deciding what to do, keeping it scoped, proving what happened, and making integration deliberate.

01 / PLAN

Start with an outcome

Describe the result. Axiom breaks larger requests into scoped tasks, dependencies and explicit acceptance criteria.

02 / BUILD

Coordinate the work

Delegate independent tasks where safe, isolate worker changes in Git worktrees, and keep progress visible.

03 / VERIFY

Show the evidence

Inspect diffs and actual check results. Missing or skipped checks are not silently presented as passed.

Control is part of the product.

Agentic software should be useful without becoming a black box.

Review before integration

Task worktrees and selective change review are designed to keep generated work inspectable. A successful agent response alone is not proof that a task is ready.

Local project boundaries

The desktop runtime binds to loopback and works in the folder you choose. File access is scoped, and secrets are not meant to be written into project memory.

Optional model routing

Use supported providers directly or connect an existing OmniRoute-compatible endpoint. Axiom does not require OmniRoute to operate.

Honest platform status

Windows x64 is the documented desktop installer target. Android APKs are debug-signed preview builds. Other desktop platforms are not advertised as downloadable.
