# Historical repository audit

This document records the initial audit made before Axiom completed its move to a standalone Electron application. It is historical context, not a description of the current source tree.

The initial audit described an earlier TypeScript/SolidJS renderer hosted by a VS Code extension. That architecture has since been removed. Current product architecture, build commands, security boundaries, and validation status are documented in [AXIOM_STANDALONE_IMPLEMENTATION.md](../AXIOM_STANDALONE_IMPLEMENTATION.md) and [README.md](../README.md).

Do not use the findings or validation caveats below as current instructions. In particular, references to extension packaging, extension-host APIs, and the old extension build are obsolete.
